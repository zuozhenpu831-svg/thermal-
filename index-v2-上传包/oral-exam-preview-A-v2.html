蓝色诺瓦学院 · 物化融合大主题"热力学"

怎么使用这一页

这不是题库，是考察范围告知。本板块完成后，教师会从下面 11 个考察方向中抽 2-3 道，与你做 15-20 分钟的深度对话。

教师做口试时不一定用原题——可能改情境、加追问、要求你即兴推导。所以"背答案"没用，关键是你能用自己的话讲清楚物理图像。

正确的备考方式是：每道题都过一遍，自己讲一遍，看能不能讲清楚。如果某道你自评讲不通，回到任务卡或与 AI 多对话几轮再来。

评分维度：概念准确性 / 推理过程 / 应对追问 / 批判性 —— 教师在四个维度上都看你的反应，不是只看你给出的"答案"。

考察方向题目 共 11 道 · 教师抽 2-3 道
1
基础
解释为什么"热量"不能作为系统"拥有"的量。
考察方向：状态量 vs 过程量的核心区分。能讲清"内能是系统拥有的状态量，热量是能量传递的过程量"——是否真懂热力学语言。
2
基础
一杯 80°C 的水含有 1000 焦耳的热量——这句话有什么问题？
考察方向：状态量与过程量的语言陷阱。看你能不能识别"含有热量"是错误表述，并改写为正确说法（"含有 1000 J 的内能"或"传递了 1000 J 的热"）。
3
中等
一个气球在太阳下膨胀了。请用热力学第一定律分析这个过程中 Q、W、ΔU 的变化。
考察方向：真实情境中对 ΔU = Q + W 的应用。判断三个量的正负号——Q 从太阳吸热（+）、气球对外做功（W < 0）、ΔU 是两者代数和；并能给出温度变化的物理解释。
4
中等
有人说"摩擦生热违反了能量守恒定律，因为热是被创造出来的"。你怎么反驳？
考察方向：能量守恒的本质 + 思辨力。看你能不能把"机械能转化为内能"讲明白，并指出对方混淆了"创造能量"和"能量形式转化"。
5
较难
绝热容器中的理想气体自由膨胀到真空（无阻力）。Q = ?、W = ?、ΔU = ? 温度变化？
考察方向：四个量都是 0 的"反直觉情境"。能不能讲清：无阻力 → W = 0；绝热 → Q = 0；所以 ΔU = 0；理想气体内能只与 T 有关 → ΔT = 0。还要顶住"膨胀就该降温"的追问。
6
中等
解释为什么循环过程 ΔU = 0。
考察方向：状态量的回归特性。回到原状态 → 内能是状态量，所以 ΔU = 0；进而推出 Q_净 = -W_净 = 系统对外净功，与 PV 图围合面积对应。
7
中等
解释为什么 PV 图下面积 = 功。
考察方向：从 W = P·ΔV 出发的微元积分图像。能讲清"把过程切成无数小段，每段近似等压，加起来就是面积"；并能区分等压、等温、等容三种过程的图形与正负号。
8
较难 物化融合
解释亨利定律与第一定律的能量层面联系（融合题）。
考察方向：跨学科理解。气体溶解过程的内能 / 焓变化 + 温度对溶解度的影响（k_H 随 T 变化），与气泡水果实验串起来。能联系实验数据更佳。
9
中等
解释打气筒发热与冰箱压缩机发热的相同与不同（情境题）。
考察方向：真实情境的能量分析。相同：都是外界对气体做功 → 内能增加 → 温度升高；不同：打气筒是开放系统（气体放出去），冰箱压缩机是封闭循环（气体反复参与）。
10
中等
比较等温膨胀与等温压缩的 Q、W、ΔU。
考察方向：四个典型过程之一。等温 → ΔU = 0；膨胀对外做功 → W < 0、Q > 0；压缩反之。能在 PV 图上指出两条路径互为镜像。
11
较难
用第一定律解释为什么吹气和呼气感觉温度不同。
考察方向：看似日常的反直觉现象。吹气（嘴小、出气快）→ 接近绝热膨胀 → 气体降温；呼气（嘴大、慢）→ 接近等温 → 温度跟体温接近。能讲出两种过程的物理差异即过关。
